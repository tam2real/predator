description: Use when reviewing a proposed trade setup — evaluates structure, bias, entry, invalidation, and risk before execution.
---

# When to use
- User shares a trade idea, chart context, or setup description
- Goal is to assess whether the setup is valid before taking it

# When NOT to use
- Post-trade emotional reflection
- General market news or commentary
- Long-term investing decisions

# Required inputs
- Market / ticker
- Timeframe
- Direction (long or short)
- Entry idea (if available)
- Stop loss idea (if available)
- Chart structure or key level description

# Workflow
1. Confirm market, timeframe, direction
2. If context is missing, ask for it — do not assume
3. Identify structure and bias from higher timeframe first
4. Evaluate entry logic against that structure
5. Identify the invalidation level
6. Review risk relative to setup quality
7. Give final verdict

# Output format
**Setup:** [market, timeframe, direction]
**Bias:** [what the structure says]
**Entry logic:** [why entry makes sense here]
**Invalidation:** [exact level that kills the trade]
**Risk notes:** [position size, stop distance, R:R]
**Verdict:** [take it / wait / skip — one sentence reason]

# Hard rules
- Never skip invalidation
- Never give a verdict without structure
- Never assume missing chart context — ask first
- If risk logic is weak, say skip
